多提供商，按功能绑定

DeepSeek / OpenAI / 硅基流动 / 基元律动 / Ollama 等预设，聊天、识图、生图、搜索、语音各自绑定模型，也可自定义兼容端点。

一键配置

首次启动粘贴一个 DeepSeek Key，自动配齐聊天、识图、标题、联网搜索与语音服务。

微信式语音

按住说话、上滑取消、松手自动转写发送；音色按官方文档内置，支持自定义音色 ID。

附件与链接

图片 / PDF / Word 解析提问；粘贴网址自动读正文作上下文，仅用户链接、拒绝内网地址。

生图与图生图

尺寸张数由模型按你的话推断、不改原文；参考图二次创作跨厂商可用。

隐私与安全

密钥不进日志与导出包；跨主机重定向自动剥离鉴权头；渲染管线消毒；停止即真取消请求。
